# Mariam Fatima — Portfolio

Static portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — styling and responsive layout
- `script.js` — interactions, skills, projects, timeline and contact form
- `attached_assets/` — portfolio images and CV

## Run locally
Open `index.html` in a browser.

## Deploy to Vercel
Import the GitHub repository as a static project. No build command is required.
