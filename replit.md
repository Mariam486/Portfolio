# Portfolio — Mariam Fatima

A static personal portfolio website for Mariam Fatima, Software Engineering student and Graphic Designer.

## Stack

- Plain HTML, CSS, and JavaScript — no build step required
- Google Fonts (Fraunces, Inter)

## How to run

The site is served with `npx serve` on port 5000:

```
npx serve . -p 5000 --no-clipboard
```

The "Start application" workflow handles this automatically.

## Project structure

- `index.html` — main page (hero, about, skills, projects, experience, contact sections)
- `style.css` — all styles, including dark/light theme variables
- `script.js` — scroll animations, theme toggle, dynamic content rendering
